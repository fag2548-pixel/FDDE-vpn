# 🚀 FDDE VPN

Агрегатор бесплатных VPN-конфигураций. Все ключи собраны из открытых источников, очищены от рекламы и отсортированы с использованием искусственного интеллекта (ИИ) по реальной скорости.

## 📌 Расшифровка префиксов (Что означают буквы?)

В названии каждого сервера есть специальный префикс. Он показывает, в каких условиях этот сервер будет работать лучше всего:

*   **🟢 AL (Обычный)** — Работает на обычном интернете (домашний Wi-Fi, мобильный интернет без ограничений). Отлично подходит для повседневного использования, YouTube и серфинга.
*   **🔵 BL (Белый список)** — Специальные серверы для обхода блокировок в условиях жестких ограничений (например, когда провайдер режет весь трафик, кроме разрешенных сайтов). Если у вас не работает обычный интернет через VPN, попробуйте этот сервер.
*   **🟡 СРЕДНИЙ** — Пинг от 100 до 150 мс. Работать будет, но страницы могут открываться с небольшой задержкой.
*   **🐢 МЕДЛЕННЫЙ** — Пинг выше 150 мс. Подходит только для экстренных случаев, когда все остальные сервера не работают.

## ⚠️ Важно знать
1. Все конфигурации предоставляются «как есть» (AS IS). Мы не владеем этими серверами и не гарантируем 100% стабильность, так как это бесплатные публичные узлы.
2. Сервера могут переставать работать. Если сервер в статусе `BD` (Bad) или не подключается — просто выберите другой.
3. **Безопасность:** Не рекомендуется использовать бесплатные сервера для входа в банковские приложения или передачи конфиденциальных данных.

⚠️ Если сервер не работает (ошибка подключения, нет интернета):

1. Ваш провайдер может блокировать этот тип соединения (DPI). Попробуйте другой сервер.
2. Сервер мог быть перегружен или заблокирован. Выберите другой из списка (самые быстрые — с огоньком 🔥).
3. Если не работают все обычные сервера (AL), попробуйте сервер с пометкой BL (белый список) — он лучше обходит блокировки.
4. Если не подключается ни один сервер, обновите подписку в приложении (потяните список вниз или нажмите кнопку обновления).
