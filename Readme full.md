# 📖 Подробное описание FDDE Vpn

### 📌 Расшифровка префиксов
| Префикс | Значение | Рекомендации |
| :--- | :--- | :--- |
| **🟢 AL** | Обычный | Для Wi-Fi и мобильного интернета. |
| **🔵 BL** | Белый список | Для обхода жестких блокировок (когда обычные сервера не работают). |
| **🟡 СРЕДНИЙ** | Пинг 100–150 мс | Для серфинга, видео может грузиться с паузой. |
| **🐢 МЕДЛЕННЫЙ** | Пинг >150 мс | Экстренный случай. |

---

## 📲 Как добавить подписку в Happ (Инструкция)

1. Скопируйте ссылку на подписку из основного файла `README.md` (она начинается с `https://raw.githubusercontent.com/...`).
2. Откройте приложение **Happ**.
3. Нажмите на значок **«+»** (плюс) в правом верхнем углу.
4. Выберите **«Добавить из буфера обмена»** (или «Импорт из URL»).
5. Приложение автоматически скачает список серверов.
6. Нажмите на подписку и выберите сервер, чтобы подключиться!

## ❓ Частые вопросы (FAQ)

<details>
  <summary><b>Почему сервер не подключается?</b></summary>
  
  * Ваш интернет-провайдер может блокировать этот тип соединения (DPI). Попробуйте выбрать другой сервер из списка.
  * Сервер мог быть перегружен. Попробуйте сервер с пометкой 🔥 (он самый быстрый).
  * Если не работают все обычные сервера (AL), попробуйте сервер с пометкой **BL** (белый список).
</details>

<details>
  <summary><b>Почему пинг (задержка) такой высокий?</b></summary>
  
  Пинг зависит от расстояния до сервера. Чем дальше сервер (например, Канада), тем выше пинг. Для игр и видеозвонков выбирайте сервера с наименьшим пингом (до 100 мс).
</details>

<details>
  <summary><b>Как часто обновляются сервера?</b></summary>
  
  Список настроен на автообновление каждые 12 часов. Вы также можете обновить его вручную в приложении Happ (потяните список вниз или нажмите кнопку обновления).
</details>

<details>
  <summary><b>Это безопасно?</b></summary>
  
  Все конфигурации предоставляются «как есть» (AS IS). Это публичные бесплатные сервера. **Не рекомендуется** использовать их для входа в банковские приложения или передачи конфиденциальных данных.
</details>

<details>
  <summary><b>Что делать, если не работает ни один сервер?</b></summary>
  
  Если ни один сервер из списка не подключается, скорее всего, создатель подписки в данный момент не может найти новые рабочие конфигурации (бесплатные сервера часто блокируются или умирают). В таком случае остается только ждать следующего обновления списка.
</details>
