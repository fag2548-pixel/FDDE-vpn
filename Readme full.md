# 📖 Подробное описание FDDE Vpn

### 📌 Расшифровка префиксов
| Префикс | Значение | Рекомендации |
| :--- | :--- | :--- |
| **🟢 AL** | Обычный | Для Wi-Fi и мобильного интернета. |
| **🔵 BL** | Белый список | Для обхода жестких блокировок (когда обычные сервера не работают). |

| **📺 YT** | Для YouTube | Оптимизирован для обхода замедления видео. |

## 📲 Как добавить подписку в Happ (Инструкция)

У нас есть два варианта подписки. Вы можете использовать оба одновременно.

### Вариант 1: Обычный конфиг (ручной выбор)
1. Скопируйте ссылку на файл **`Vpn config`** из основного описания (`README.md`).
2. Откройте приложение **Happ**.
3. Нажмите на значок **«+»** (плюс) в правом верхнем углу.
4. Выберите **«Добавить из буфера обмена»**.
5. Нажмите на подписку и выберите сервер для подключения.

### Вариант 2: Авто-балансер (лучший AL)
1. Скопируйте ссылку на файл **`balancer.json`** из основного описания (`README.md`).
2. Добавьте её в Happ таким же способом (через «+»).
3. **Важно:** Этот конфиг будет автоматически проверять пинг всех быстрых серверов (AL) и всегда подключаться к самому быстрому. Вам не нужно выбирать сервер вручную.

## ❓ Частые вопросы (FAQ)

<details>
  <summary><b>Почему сервер не подключается?</b></summary>
  
  * Ваш интернет-провайдер может блокировать этот тип соединения (DPI). Попробуйте выбрать другой сервер из списка.
  * Сервер мог быть перегружен. Попробуйте сервер с пометкой 🔥 (он самый быстрый).
  * Если не работают все обычные сервера (AL), попробуйте сервер с пометкой **BL** (белый список).
</details>

<details>
  <summary><b>Что делать, если не работает ни один сервер?</b></summary>
  
  Если ни один сервер из списка не подключается, скорее всего, создатель подписки в данный момент не может найти новые рабочие конфигурации (бесплатные сервера часто блокируются). В таком случае остается только ждать следующего обновления списка (оно происходит каждые 12 часов).
</details>

<details>
  <summary><b>Это безопасно?</b></summary>
  
  В целом — **да, это безопасно**, так как весь трафик передается по защищенному протоколу (HTTPS/TLS или Reality), который используется и на обычных сайтах. Владелец VPN-сервера видит только домены, которые вы посещаете (например, `youtube.com`), но **не может прочитать ваши пароли или переписку**.
  
  **⚠️ Важное правило:** Если при заходе на любой сайт браузер выдает красное предупреждение («Ваше соединение не защищено» или «Возможна атака») — **НИКОГДА не нажимайте «Продолжить»**, если у вас включен VPN. Это может означать попытку подмены сайта. Лучше сразу переключитесь на другой сервер.
  
  *Не рекомендуется использовать бесплатные сервера для входа в банковские приложения.*
</details>

<details>
  <summary><b>Можно ли качать торренты?</b></summary>
  
  ❌ **НЕТ**. Использование торрентов (P2P) строго запрещено на этих серверах. Владельцы серверов блокируют IP-адреса за торрент-трафик, и сервер может умереть для всех пользователей в течение нескольких часов.
</details>
