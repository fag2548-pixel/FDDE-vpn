### 🔒 Резервный вариант: AmneziaWG (папка `amnezia`)

Если VLESS-сервера не работают или YouTube сильно тормозит, используйте **AmneziaWG** — это протокол с обфускацией, который отлично обходит блокировки.

В папке **`amnezia`** лежат готовые файлы конфигурации.

**Как добавить сервер:**
1. Установите приложение **AmneziaVPN** (или AmneziaWG) из Play Маркета / App Store.
2. Скачайте файл с расширением `.conf` из папки `amnezia`.
3. Откройте AmneziaVPN, нажмите «+» (Добавить).
4. Выберите **«Импорт файла»** (или «Из файла») и укажите скачанный `.conf`.
5. Готово. Сервер появится в списке.

**Важно:** Если YouTube тормозит на VLESS — просто переключитесь на AmneziaWG. Он лучше держит видео.
